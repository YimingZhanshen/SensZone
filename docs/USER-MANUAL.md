# 《SensZone（灵敏域）FPS灵敏度区间查找软件 V1.4》用户操作手册

## 1. 软件概述

### 1.1 软件名称与用途

本软件全称为《SensZone（灵敏域）FPS灵敏度区间查找软件》（以下简称"本软件"），当前版本 V1.4。

本软件是一款基于运动学分析与 Fitts 定律的 FPS（第一人称射击）游戏鼠标灵敏度区间查找工具。用户在浏览器中完成两组标准化瞄准测试（离散甩枪任务与平滑跟踪任务）后，软件输出**个人最优灵敏度平台区间**（一个区间，而非单一数值），并提供多游戏灵敏度换算表，帮助用户科学地确定与验证自己的鼠标灵敏度设置。

### 1.2 运行环境

- 现代桌面浏览器：Chrome 90+ 或 Edge 90+（推荐 Chromium 内核浏览器以获得完整的 Pointer Lock 原始输入支持）
- 操作系统：Windows / macOS / Linux（需关闭操作系统与驱动层的鼠标加速）
- 显示器与鼠标：任意游戏鼠标；建议使用 800–3200 DPI 档位
- 网络环境：在线使用需可访问部署站点；离线时可使用本地副本（file:// 协议完整可用）

### 1.3 适用人群

希望测量、校准或验证 FPS 游戏鼠标灵敏度的玩家。软件默认参数按 800 DPI、CS2 类游戏预填，其他游戏可通过预设或自定义 yaw 值接入。

## 4. 测试前准备（检查清单）

开始测试前，请逐项确认菜单页"测试前检查清单"：

1. **关闭操作系统鼠标加速**：Windows 需取消"提高指针精确度"；macOS 需关闭"指针移动速度"相关的自动加速。
2. **关闭驱动层鼠标加速**：在鼠标驱动（如 G HUB / Razer Synapse 等）中确认未启用任何加速/平滑/角度捕捉。
3. **勾选"以全屏开始"**（推荐）：全屏可保证视角转动与鼠标移动的映射一致性。
4. **保持坐姿与手腕稳定**：测试过程中保持与日常游戏一致的握持姿势。

软件会自动检测输入模式：若浏览器不支持绕过系统加速的原始输入（unadjustedMovement），报告将标注警告。

## 5. 完整操作流程

### 5.1 填写设置

1. 选择游戏：CS2 / Apex / Valorant / Overwatch 2，或选择 Custom（自定义）。
2. 若选择 Custom：填写该游戏的水平 FOV 与 yaw 值（°/count，可在社区换算表查询）；软件会对 yaw 做反算一致性校验，校验未通过会给出提示。
3. 选择游戏内纵横比：4:3（含拉伸）或 16:9 原生。
4. 填写鼠标 DPI 与当前游戏内灵敏度。
5. 选择测试任务：甩枪 + 跟枪（推荐）/ 仅甩枪 / 仅跟枪。
6. （可选）填写鼠标垫宽度，用于物理约束校验（180° 转身是否 ≤ 垫宽 45%）。
7. 确认预览行显示的 cm/360、eDPI 与预计用时无误。

【图 5：设置项填写示例】

### 5.2 开始测试

1. 点击"开始测试"按钮。
2. 按页面提示点击画面以锁定鼠标指针（Pointer Lock）。
3. 测试全程约 9–11 分钟（默认 24 试次/条件 + 6 档 × 15 秒跟枪）。

### 5.3 甩枪任务操作

1. 每次试次开始前，视角自动回中，出现灰色预览靶。
2. **开始移动鼠标即开始计时**（无反应时间惩罚）。
3. 将准星甩向绿色靶子并单击左键；单次试次限时 1.5 秒，超时判失败。
4. 命中显示反馈后自动进入下一试次；测试中未"武装"（起始静止不充分）越过标靶的试次会被跳过，不计成绩。

【图 6：甩枪任务进行中与命中反馈】

### 5.4 跟枪任务操作

1. 绿色靶子将在场景中连续平滑移动，共 15 秒。
2. 用准星持续跟随靶子中心，尽量贴合。
3. 软件记录 RMS 偏差、在靶时间百分比与准星滞后毫秒数。

【图 7：跟枪任务进行中】

### 5.5 暂停与恢复

1. 测试中按 ESC 可暂停并解锁鼠标。
2. 暂停后可选择"继续"（进度保留，计时自动平移修正）或"放弃本次测试"。
3. 意外关闭页面后，再次进入菜单会显示"恢复上次会话"按钮。

### 5.6 查看报告

测试完成后自动进入报告页，包含：

- 双任务总览：甩枪最优平台 + 跟枪最优平台 + 重叠区；每档"调整后成绩差异 < 8%"视为等价。
- 统计口径说明：MT 经 ANCOVA 难度归一 + 加权二次拟合 + bootstrap 置信区间。
- 甩枪时间分解：验证时间与停顿时间（反映"确认对准"的成本）。
- 诊断图：带符号端点误差（正=过冲，负=欠冲）、子动作数、跟枪 RMS 与滞后双面板。
- 综合推荐：拖动甩枪/跟枪权重滑块（0–100%）合成推荐值 + 多游戏换算表。
- 物理约束：垫宽校验结果。

## 7. 常见问题

**Q1：测试时鼠标"飘"或结果异常？**
检查第 4 章清单：系统与驱动层鼠标加速是否全部关闭；报告页会标注输入模式（raw/adjusted），显示 adjusted 时结果可能受系统加速污染。

**Q2：命中率很低怎么办？**
先确认握持姿势与日常一致；命中率低于 85% 时报告会给出警告，此时建议先降低任务难度熟悉操作再正式测试。

**Q3：换游戏后灵敏度怎么换算？**
使用报告页的"多游戏换算表"：按综合推荐 cm/360 直接换算为各游戏灵敏度数值（基于各游戏 yaw 常数）。

**Q4：为什么输出的是区间而不是单一数值？**
单点数值会放大抽靶与状态波动的影响；平台区间内各档"调整后成绩差异 < 8%"，统计上等价，区间更能反映真实可调范围。

**Q5：数据会上传吗？**
不会。所有测试数据仅保存在本机浏览器 localStorage 中，清除浏览器数据会同时清除历史记录。

**Q6：刷新率不同的显示器结果可比吗？**
可比。软件全程使用 delta-time，60Hz 与 360Hz 显示器在协议上公平。
