## 2. 源代码结构

软件为纯前端单页应用，零运行时第三方依赖，全部源代码位于仓库 `src/` 目录与根目录 `index.html`。模块清单（加载顺序即 index.html 中脚本声明顺序）：

```
index.html        入口页面与样式（含全部界面骨架与内联 CSS）
src/version.js    版本号单源（SZ.VERSION）
src/math.js       灵敏度换算 / Fitts ID / 球面几何 / 种子随机
src/kinematics.js 重采样 + Butterworth 滤波 + 子动作分割（论文 Algorithm 1）
src/stats.js      加权二次拟合 / bootstrap / Spearman
src/i18n.js       界面文案（zh-CN / en 双语）
src/render.js     Canvas 2D 场景渲染（标靶 / 相机投影 / 水印）
src/input.js      Pointer Lock（原始输入）+ 合并事件采样
src/task-flick.js 离散甩枪任务状态机（自动回中 + 移动起始计时）
src/task-track.js 平滑跟踪任务（恒速巡航 + 余弦转弯轨迹）
src/session.js    条件生成 / 双任务调度 / 断点续测
src/analysis.js   ANCOVA 归一 + 加权拟合 + 平台检测 + 报告生成
src/charts.js     MT 曲线 / 跟枪 RMS 与滞后双面板 / 历史趋势图
src/report-image.js 报告分享图（Canvas 离屏绘制）
src/ui.js         界面装配 / 报告渲染 / 设置与历史
src/main.js       应用主循环与页面装配
sw.js             Service Worker（PWA 离线缓存）
scripts/*.mjs     开发辅助脚本（版本号统一、图标生成、源码导出）
test/*.cjs        冒烟测试与全会话集成测试
```
